# Berry — Web Technologies Assignment 01

## Assignment coverage
- HTML5 + Tailwind CSS
- 5 pages: Home, About, Contact, Sign In, Sign Up
- Consistent responsive navbar and footer
- Unique page titles and favicon
- 10+ Tailwind UI components on each page
- Responsive desktop, tablet and mobile layouts
- Functional Contact form prepared for Formspree
- Organized project structure: `index.html`, `src/pages/`, `assets/`

## Run locally
Open `index.html` using VS Code Live Server.

## Contact form
The Contact page uses Formspree. Keep the real Formspree action URL already configured in `src/pages/contact.html`. If the file still contains `YOUR_FORM_ID`, replace it with the endpoint from your Formspree form.

## Sign In / Sign Up
These are front-end demonstration pages. They include browser validation, password visibility, password-strength feedback, confirmation validation, responsive UI, and demo success messages. A real authentication backend is outside the stated assignment requirements.
